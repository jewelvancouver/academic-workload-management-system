Academic Workload Management System

Project Purpose

The Academic Workload Management System is a Python-based academic project designed to help organise and manage academic workload information.

The project demonstrates the application of object-oriented programming, file handling, exception handling and basic system design in Python.

Problem Being Addressed

Students can have multiple academic activities and tasks to manage, making it difficult to keep track of their workload in an organised way.

This project provides a simple computer-based system for storing and managing academic workload information instead of relying entirely on manual records.

Technologies Used

* Python
* Object-Oriented Programming (OOP)
* Text-file data storage
* Exception handling
* Visual Studio Code

Main Features

The system is designed to demonstrate features such as:

* Adding academic workload information
* Viewing stored workload information
* Organising academic tasks
* Updating workload information
* Removing workload information
* Saving information using text files
* Reading information from stored files
* Handling invalid input and errors
* Applying object-oriented programming principles

How to Run the Project

1. Install Python

Download and install Python if it is not already installed on your computer.

2. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/academic-workload-management-system.git
```

3. Open the project

Open the project folder using Visual Studio Code or another Python-compatible development environment.

4. Run the program

Run:

```bash
python main.py
```
